# Repaso Psicopatología General

Repaso interactivo para el examen final de **Psicopatología General** — Escuela de Ciencias Psicológicas, Centro Universitario Metropolitano, USAC. Docente: Dr. Rolando Lemus Rodas.

👉 **[Abrir el repaso](https://jossuechanquin.github.io/repaso-psicopatologia/)**

## Qué incluye

| Modo | Contenido |
| --- | --- |
| **Quiz** | 134 preguntas de opción múltiple con puntaje, racha y explicación tras cada respuesta |
| **Tarjetas** | 45 términos para memorizar la Serie I de definiciones |
| **Tablas** | El cuadro de los ocho modelos teóricos para completar |
| **Caso GLADP** | El caso clínico de JJ resuelto paso a paso, siguiendo el proceso diagnóstico |

Al entrar se escoge entre dos rutas:

- **Ruta esencial** — 75 preguntas: solo lo que aparece repetido en los exámenes reales o sale directo de las diapositivas.
- **Ruta completa** — 134 preguntas: todo el banco, incluidas las de refuerzo.

Las preguntas se pueden filtrar por bloque (primer parcial, segundo parcial, GLADP) y la página guarda las falladas para repasarlas después.

## Cómo funciona

Es una sola página sin dependencias de servidor. Todo corre en el navegador. Funciona con teclado: `1`–`4` para responder, `Enter` para avanzar. Tiene modo claro y oscuro.

## De dónde salió el contenido

Del repaso del primer parcial, del segundo parcial, de las presentaciones del curso y del ejercicio de diagnóstico GLADP. Las preguntas marcadas con **★** son las de mayor probabilidad: aparecen en más de un examen o salen de una diapositiva.

## Avisos

Material de estudio hecho por estudiantes, no material oficial del curso. Hay puntos donde las fuentes se contradicen entre sí; ante cualquier duda, manda la versión de la diapositiva del catedrático. Dos ejemplos:

- La diapositiva atribuye a Sartre «la esencia precede a la existencia»; la formulación canónica es la inversa.
- El repaso de clase define la normalidad teleológica como «lo común, lo frecuente», que en realidad corresponde al significado estadístico.
